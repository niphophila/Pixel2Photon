Simulated Real-Time Lighting Control: TouchDesigner & Unreal Engine (now kith)

This project demonstrates the integration of TouchDesigner and Unreal Engine for virtual lighting simulation and remote control. It provides a bascic framework for bridging a a touchdesigner programming and control interface with a high-fidelity virtual production environment in unreal engine to facilitate pre-visualization and system testing.

**Core Objectives**

  - System Integration: Establishing a real-time data bridge between TouchDesigner (control) and Unreal Engine (simulation).
  - Protocol understanding: Developing workflows for DMX and Art-Net addressing and signal routing. Make it make sense!
  - Pre-Visualization: Creating a virtual environment for testing scenography and lighting logic without physical hardware (other than a computer).

**Key Take-aways**

  - TD Control Interface: A TouchDesigner-based UI for managing lighting parameters.
  - Virtualising!: Unreal Engine simulation for real-time visual feedback of lighting designs.
  = Hardware-Free Testing: Capability to program, address, and simulate lighting systems prior to physical deployment.
